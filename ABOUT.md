# About

Kraken Live Quant Trader is an experimental Python trading engine created by Matthew Johns as part of a broader cryptocurrency-strategy research archive.

It combines signal generation, universe selection, execution, state persistence, an audit trail, and layered risk controls in one runnable system. The repository was separated from the larger Crypto Trading Bots collection because it has an independent architecture and operational lifecycle.

This repository preserves the strategy as research software. Publication does not imply profitability, safety, regulatory suitability, or production readiness.
